See no Evil 简体中文汉化补丁
================================

本补丁不包含任何游戏本体文件，需要你自己拥有 See no Evil 完整版（Bigfingers.ca 发售，Unity 4.1 版本）。

作者授权：等待中。在作者回复之前，请不要公开转发本补丁。

安装方法
--------
1. 先关闭游戏。
2. 把压缩包里 SeeNoEvil_CHS 文件夹中的所有内容复制到游戏根目录（与 See_No_Evil.exe 放在一起）。
3. 双击运行“安装汉化.bat”。
   安装前会自动把原始文件备份到“汉化备份”文件夹；如果游戏版本不匹配，会自动还原并提示失败。

卸载方法
--------
双击运行游戏根目录中的“卸载汉化.bat”，即可还原为英文原版。

关于文字指令
------------
本游戏需要按回车键输入文字指令。对话中用【】括起来的词就是可以输入的指令：
- 可以输入中文，例如：提供剃刀换取刮毛、召唤Boulder、查看蜂蜜
- 也可以照旧输入英文，例如：OFFER RAZOR FOR SHAVE、SUMMON BOULDER
- 角色名保持英文（Orsino、Barrod、Boulder、Agmago、Mags、Ciz、Hup），输入时用英文即可
- 咒语（FULMINUS、PYRAX 等）保持英文
- 如果中文输入法在游戏里无法使用，请直接输入英文指令

补丁内容
--------
- 全部对白、物品与地点描述、结局文本的简体中文翻译
- 界面文字、地点名称、恶魔状态提示、制作人员名单的翻译
- 新增中文像素描边字体（基于思源黑体 Source Han Sans，SIL Open Font License 1.1）
- 中文自动换行与中文文字指令支持（SNE_CN.dll）
